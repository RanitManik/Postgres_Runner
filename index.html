Postgres Runner — Instant In-Browser PostgreSQL 16 Playground & SQL Sandbox

Postgres Runner is an in-browser developer tool that runs a full PostgreSQL 16 database directly in your web browser using WebAssembly. Practice SQL queries, test database schemas, execute multi-statement scripts, inspect tables and indexes with an interactive Schema Explorer, and manage multiple persistent playgrounds saved locally in IndexedDB.
